Ատրիբուտներ - Attributes
Ատրիբուտները նախատեսված են,որպեսզի կարողանանք միևնույն թեգերից կարողանանք ընտրել մեր ուզածը։Ատրիբուտները լինում են երեք տեսակի․՝
  1. Պարտադիր - Պարտադիր են համարվում այն ատրիբուտները,առանց որոնց թեգերը չեն կարող աշխատել։(Օրինակ href ատրիբուտը a թեգի համար,առանց որի հղման թեգերը չեն կարող աշխատել։Src ատրիբուտը img թեգի համար,որը ցույց է տալիս նկարի ճանապարհը)։
  2. Ցանկալի - Ցանկալի են համարվում այն ատրիբուտները,որոնց օգտագործուը պարտադի չէ։Օրինակ target ատրիբուտը a թեգի համար։
  3. Գլոբալ - Գլոբալ ատրիբուտները․՝ class և id աշխատում են բոլոր թեգերի հետ։Նրանց միջոցով կարողանում ենք վերցնել թեգերը և օգտագործել այլ դոկումենտների մեջ։Նրանց տարբերությունը այն է,որ նույն անունով class ատրիբուտը մենք կարող ենք օգտագործել տարբեր թեգերի համար,իսկ id - ին ընդունված է տալ միայն մեկ թեգի։
Ցանկեր - Lists
< ol > < /ol >
Զույգ թեգը նախատեսված է համարակալված ցանկեր ստեղծելու համար (Ծագել է անգլերեն Orderd-List արտահայտությունից)։Այն ունի ցանկալի ատրիբուտներ․՝ type ատրիբուտը օգնում է մեզ համարակալումը փոխել տառերով կամ թվերով։ Start ատրիբուտը օգնում է մեզ համարակալումը սկսել մեր ցանկացած թվից կամ տառից։
< li > < /li >
Զույգ թեգը նախատեսված է ol թեգի մեջ տվյալներ լրացնելու համար։
< ul > < /ul >
Զույգ թեգը նախատեսված է չհամարակալված ցանկեր ստեղծելու համար(Այն ծագել է Unordered-list արտահայտությունից)։Նրա մեջ տվյալները նույնպես լրացվում են li թեգի օգնությամբ։
Աղյուսակ - Table
< table > < /table >
Զույգ թեգը նախատեսված է աղյուսակ ստեղծելու համար։Սակայն այս թեգը միայն տարածքն է ստեղծում։Այն ունի երկու իրեն հատուկ ատրիբուտ․՝ width (Նախատեսված է աղյուսակի երկարությունը կարգավորելու համար) և border (Նախատեսված է անկյունագծերը նշելու համար )։
< tr > < /tr >
Զույգ թեգը նախատեսված է աղյուսակի մեջ տող ստեղծելու համար։Սակայն այս թեգը կրկին միայն տարածքն է ստեղծում
< th > < /th >
Զույգ թեգը նախատեսված է տողի մեջ վանդակ ստեղծելու համար։Ընդ որում նրա մեջ գրված տեքստը պատկերվում է ավելի հաստ քան այլ վանդակներում։
< td > < /td >
Զույգ թեգը նախատեսված է տողի մեջ վանդակ ստեղծելու համար։ Նրա մեջ գրված տեքստը պատկերվում է սովորական տառատեսակով։
Div
div թեգը նախատեսված է իրար հետ կապված թեգերը մեկ վայրում հավաքագրելու համար։ Օրինակ եթե մենք ունենք հարյուրավոր թեգեր որոնք նախատեսված են մի քանի բաժինների համար, ապա կարող ենք առանձնացնել թեգերը ` յուրաքանչյուրը իրենց բաժիններով, և գցել համապատասխան div - ի մեջ։ Մեկ div - ի մեջ մենք կարող ենք գցել հարյուրավոր div - եր, կարևորը նրանց class - ները կամ id - ները տարբեր լինեն։ div թեգը զույգ է։ Css - մի շարք գրադարանների կառուցվածքի հիմքում հենց div թեգն է ընկած։
Տնային աշխատանք․՝ Ստեղծել համարակալված և չհամարակալված ցանկեր։ Ստեղծել աղյուսակ։ Օգտագործել div թեգը։ Կրկնել անցած դասը( Խորհուրդ է տրվում առաջին տնայինը ևս մեկ անգամ գրել )։
