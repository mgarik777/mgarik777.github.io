< !Doctype HTML >
Սահմանում է դոկումենտի տիպը և հաղորդում է բրաուզերին և ռեդակտորին։
< HTML lang = "en" > < /html >
Սահմանում է լեզուն,որով պետք է գրվեն թեգերը։
< head > < /head >
Սահմանում է փաստաթղթի մասին տեղեկատվություն և իր մեջ ներառում է բոլոր ֆունկցիոնալ հղումները։
< Meta-charset-utf8 >
Տալիս է հնարավորություն կայքի մեջ օգտագործել ցանկացած լեզու։
< body > < /body >
Իր մեջ ներառում է այն ամենը,ինչ մենք ցանկանում ենք արտապատկերել բրաուզերի մեջ։
< title > < /title >
Սահմանում է բրաուզերի վերնագիրը։
< link rel="shortcut icon" href="img/HTML.png" > տեղադրելով այս հղումը title զույգ թեգից ներքև,մենք կարող ենք վերնագրի ձախ կողքին տեղադրել նկար(30*30 կամ 40*40 չափսի)։

Հղման Թեգեր

< a href="some link" > </a >
Նախատեսված է հղման համար,որի օգնությամբ մենք շատ հեշտությամբ կարող ենք կայքի մի էջից անցնել մեկ այլ էջ։Այստեղ պարտադիր է լրացնել href ատրիբուտը և պարունակությունը։
< a href="some link" target = "_blank" > </a >
Նոր բացվող էջը կբացվի նոր պատուհանի միջոցով։
< a href="something" download > </a >
Նախատեսված է ինչ որ ֆայլեր ներբեռնելու համար։
< a href="#tag" > </a >
Նախատեսված է նույն էջի մեջ մի հատվածից մուս հատված գնալու համար։
<img src="way of the img">
