HTML LESSON 3
Fieldset - Legend
Fieldset թեգը իրենից ներկայացնում է տարածք,որի մեջ կարող ենք ավելացնել տարբեր էլեմենտներ,նրա առանձնահատկությունը կայանու է նրանում,որ նա իր մեջ ունի defolt անկյունագիծ և իր մյուս legend թեգի օգնությամբ վերնագիրը գրում է հենց իր անկյունագծի վրա։
Form
Form թեգը զույգ թեգ է և նախատեսված է մեկ կամ մի քանի տվլայներ միանգամից վերցնելու և DataBasa կամ այլ տեղ ուղարկելու համար։Այն նախատեսված է կայքի ֆունկցիոնալ մասի հետ աշխատանքի համար։Այն ունի method ատրիբուտը,որը ունի երկու արժեք․՝ get / post :Սակայն դրանց մասին կխոսենք Back - ի դասընթացների ժամանակ։
Input - Մուտքագրման դաշտեր
<input type="text" >
Սա մեզ համար ստեղծում է դաշտ,որի մեջ մենք կարող ենք մուտքագրել և տեքստ և թվեր։Այն ունի պարտադիր ատրիբուտ․՝ type,որի միջոցով մենք որոշում ենք Input դաշտի տեսակը։Այն ունի placeholder ցանկալի ատրիբուտը,որի միջոցով մենք կարող ենք Input դաշտի վրա նախապես պատկերել թե ինչ պետք է լրացվի այս դաշտում։
<label for="id">
Name
<input type="text" id="id" > < /label >

Նաև Կարող է մեր input դաշտը լինել label ից դուրս

<label for="id"> Name
< /label >
<input type="text" id="id" >
Label թեգը նախատեսված է իր պարունակության վրա click անելու դեպքում իրեն կցված input դաշտը ակտիվացնելու համար։Այն ունի for պարտադիր ատրիբուտը,որի մեջ լրացվում է այն input դաշտի id - ին,որը մենք ցանկանում ենք որպեսզի ակտիվանա label թեգի պարունակության վրա click անելուց։Ուշադրություն դարձրեք նույն id - ին երկրորդ անգամ չենք կարող օգտագործել։Այս թեգը աշխատում է բոլոր input - երի հետ։
<input type="number">
Սա input -է որի մեջ կարող ենք գրել միայն թվեր, չենք կարող օգտագործել բացատ(space), և input -ի մեջ կստեղծվի երկու կոճակ որոնց վրա սեղմելիս input -ի մեջ գրված թիվը մեկով կավելանա կամ մեկով կնվազի
<input type="email">
Սա input -է որի միջոցով կստուգվի եթե գրված չե @ ապա խնդիր կտա և կասի որ գրենք @
<input type="password">
Սա input -է որը Նախատեսված է գաղտնաբառներ գրելու համար, և նրա մեջ գրված տեքստը կամ թվերը ցույց չի տալիս
<input type="date">
Սա input -է որը Նախատեսված է ամսաթիվ ընտրելու համար
<input type="radio" >
Այս input - ի միջոցով մենք ստեղծում ենք սեռերի համար նախատեսված կոճակներ։
<input type="checkbox" >
Այս input - ը նախատեսված է հարցերի դիմաց պտիչկա դնելու համար։
<select ></select >
Select զույգ թեգը մեզ հնարավորություն է տալիս ստեղծել հարցերի պատսասխաններ մեկ պատուհանի մեջ։Այն միայն դաշտն է ապպահովվում։ Հարցի պատասխանները կամ այլ տվլայլներ լրացվում են option զույգ թեգի օգնությամբ։
<textarea ></textarea >
Այս թեգը ստեղծում է տեքստի համար նախատեսված դաշտ,սակայն ունի մեկ առանձնահատկություն ՝ մենք կարող ենք նրա չափերը փոփոխել հենց բրաուզերի մեջ։
<input type="file" >
Սա input -է որի միջոցով կարող ենք ուղարկել ֆայլեր, նկարներ, տեսանյութեր
<input type="reset" >
Այս կոճակի օգնությամբ մենք կարողանում ենք միանգամից ջնջել form թեգի մեջ գտնվող բոլոր տվյալները(Կարևոր պայման․՝ այն պետք է անպայման գտնվի form թեգի ներսում։)Այն ունի value պարտադիր ատրիբուտը,որի արժեքը հենց մեր input - ի անունն է,որի միջոցով այն երևում է բրաուզերում։
<input type="submit" >
Այս կոճակի օգնությամբ մենք կարողանում ենք միանգամից հավաքագրել և ինչ - որ տեղ ուղարկել form թեգի մեջ գտնվող բոլոր տվյալները(Կարևոր պայման․՝ այն պետք է անպայման գտնվի form թեգի ներսում։)Այն ունի value պարտադիր ատրիբուտը,որի արժեքը հենց մեր input - ի անունն է,որի միջոցով այն երևում է բրաուզերում։
<input type="button" >
Հանդիսանում է սովորական կոճակ
<button type="submit" ></button >
Հանդիսանում է սովորական կոճակ, նրա միջոցով նույնպես կարող ենք form -ոմ գրված ինֆորմացիյաները ուղարկել, այսինքն սա ունի նույն ֆունկցիոնալը ինչպես որ <input  type="submit">, խորհուրդ է տրվում օգտագործել այս button -ը քանի որ այն ավելի հարմար է, և բացի այդ բոլորը հիմնականում օգտագործում են այս button -ը
Input Attributes - Մուտքագրման դաշտի ատրիբուտներ
required
Նրա միջոցով տվյալները ուղարկվելիս կստուգվի տվյալ դաշտը լրացված է թե ոչ, եթե ոչ ապա խնդիր ցույց կտա
placeholder=" "
Նրա միջոցով կարող ենք դաշտի մեջ գրել ինչոր նկարագրություն, ( երբ սկսեք գրել դաշտի մեջ նկարագրությունը կկորչի )
value=" "
Նրա միջոցով կարող ենք դաշտի մեջ գրել ինչոր տեքստ, ( եթե սկսեք գրել դաշտի մեջ այս տեքստը չի կորչի )
minlength=" "
Նրա միջոցով կարող ենք նշել թե արնվազն քանի նիշ պետք է ունենա տվյալ դաշտը
maxlength=" "
Նրա միջոցով կարող ենք նշել թե առավելագույնը քանի նիշ պետք է ունենա տվյալ դաշտը
Տնային աշխատանք․՝ Ստեղծել Registration - Form ` Օգտագործելով բոլոր input - ները և fieldset, legend և form թեգերը։
